🐛 TROUBLESHOOTING RAPIDE:

  "CUDA out of memory"
  → Réduire batch_size dans v2_config.json
  → Ou augmenter gradient_accumulation_steps

  "Port 5000 déjà utilisé"
  → sudo lsof -i :5000  (voir qui l'utilise)
  → Ou changer port dans dashboard_pytorch.py

  "Docker not found"
  → Utiliser Option 2 (Python direct)
  → Ou installer Docker Desktop

  "Slow throughput"
  → Vérifier GPU utilization (nvidia-smi)
  → Augmenter num_workers (actuellement 4)
